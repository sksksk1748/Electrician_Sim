# 配線道場

給完全沒有電學背景的人，從零開始練到能考**室內配線丙級**的網頁遊戲。

## 八個章節

| 迴路 | 內容 |
|---|---|
| 01 電的基礎 | 電壓、電流、電阻、功率、交直流、電從發電廠到你家、為什麼要高壓輸電、單相三線、觸電危險 |
| 02 器材與安全 | 無熔絲開關、漏電斷路器、線色規定、開關種類、停電作業順序 |
| 03 配線工坊 | 7 個配線關卡，在 3D 配線板上拉線、送電測試並自動評分（功能、安全、線色） |
| 04 電箱工坊 | 組裝端子台（DIN 軌道、端子、接地端子、端板、固定座、標示條），三相四線 220/380V 進線、相指示燈、三相馬達正反轉與單相分路的負載平衡 |
| 05 三用電表 | 指針式電表操作：選檔位、讀刻度、零歐姆調整，在 3D 工作台拖曳表筆量測 |
| 06 故障偵探 | 在 3D 住家場景用電表、絕緣電阻計、檢電起子、鉤表找出斷路、短路、漏電 |
| 07 居家用電規劃 | 插座分歧接線的 3D 場景、生活中的串聯與並聯、電盤能帶多少瓦、家電配置遊戲、銅線線徑與電壓降、選線小遊戲 |
| 08 學科模擬考 | 題庫隨機 30 題 |

## 怎麼玩

不需要安裝任何東西，用瀏覽器打開 `index.html` 即可。進度存在瀏覽器裡。

配線工坊、三用電表、故障偵探與居家用電規劃章節的 **3D 場景**用 [three.js](https://threejs.org/) 繪製，會從 CDN 載入，所以需要網路連線。沒有網路或瀏覽器不支援 WebGL2 時，會自動改用原本的操作方式：配線工坊是平面配線板、三用電表是清單模式、故障偵探與居家用電規劃是線路圖。兩種方式可以隨時切換，進度共用。

## 注意

考試資訊與規則數值請以勞動部勞動力發展署技能檢定中心的最新公告為準。居家用電規劃章節的安培容量、電壓降與連續負載數值取自「用戶用電設備裝置規則」，實際設計請查閱規則原文並依現場配線方式、周溫、同管導線數校正。術科的實際手作（剝線、壓接、配管）仍需使用實體器材練習。

# 配線道場

給完全沒有電學背景的人，從零開始練到能考**室內配線丙級**的網頁遊戲。

## 六個章節

| 迴路 | 內容 |
|---|---|
| 01 電的基礎 | 電壓、電流、電阻、功率、交直流、單相三線、觸電危險 |
| 02 器材與安全 | 無熔絲開關、漏電斷路器、線色規定、開關種類、停電作業順序 |
| 03 配線工坊 | 7 個配線關卡，送電測試並自動評分（功能、安全、線色） |
| 04 三用電表 | 指針式電表操作：選檔位、讀刻度、零歐姆調整 |
| 05 故障偵探 | 用電表、絕緣電阻計、檢電起子、鉤表找出斷路、短路、漏電 |
| 06 學科模擬考 | 題庫隨機 30 題 |

## 怎麼玩

不需要安裝任何東西，用瀏覽器打開 `index.html` 即可。進度存在瀏覽器裡。

## 注意

考試資訊與規則數值請以勞動部勞動力發展署技能檢定中心的最新公告為準。術科的實際手作（剝線、壓接、配管）仍需使用實體器材練習。
